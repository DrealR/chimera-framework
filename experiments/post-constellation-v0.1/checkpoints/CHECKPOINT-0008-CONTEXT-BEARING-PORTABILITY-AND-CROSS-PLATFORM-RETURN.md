## Bounded YouTube comment-tree capability

`tools/youtube-comment-capture.js` and its runbook implement the smallest useful path on an already-open YouTube watch page.

The utility:

- is user-triggered and watch-page-only;
- reads only rendered DOM;
- expands visible comment text and visible reply/continuation controls;
- accumulates top-level/reply relationships despite ordinary DOM replacement;
- captures video, sort, thread, comment, timestamp, like, badge, and run provenance where rendered;
- pseudonymizes authors by default; displayed public identity requires explicit opt-in;
- exports JSON and readable Markdown;
- supports validated same-video resume;
- does not use API, `fetch`, XHR, cookies, storage, credentials, or engagement actions;
- stops at bounded pass, idle, and click ceilings;
- never claims completeness or representative public opinion.

No live comment export has been ingested yet. Browser-interface drift, localization, personalization, moderation, deletion, hidden replies, and incomplete loading remain known limits.
