## Bounded synthesis

### 1. The exchange loop is thicker than input / output

CAND: Input and output name what crosses a membrane, but they omit the body-specific interior and the consequence that follows. A stronger smallest useful loop is:

```text
Receive
→ Transform
→ Express / Emit / Act
→ Consequence in another body or field
→ Return and residue
↺
```

- **Receive** is broader than consume. A body can receive light, pressure, language, food, a refusal, a tool result, or a social cue.
- **Transform** preserves the distinct body's history, filters, constraints, memory, and Pause.
- **Express** names intentional articulation; **emit** also includes heat, waste, telemetry, error, and side effects that were not intended as expression.
- **Consequence** asks where the output actually lands and which body pays or gains capacity.
- **Return** permits correction from another center or later time.
- **Residue** changes what the next cycle begins from.

This is compatible with the current Spine's metabolism definition and the Cube's `Receive → Transform → Emit` cycle while adding settlement and correction.

### 2. Bodies can nest without becoming equivalent

CAND: A person, human-and-tool, feed, team, platform, community, and ecosystem can each be read as a body at a named scale. An output at one scale can be an input at another.

```text
person writes question
→ platform receives and ranks
→ another person interprets and acts
→ reply or silence returns
→ author and archive are reweighted
```

The structural loop does not prove equal consciousness, cognition, metabolism, agency, or physics across human, animal, AI, platform, and ecological bodies.

### 3. Rhythm is remembered exchange

CAND: A rhythm is not one output. It is a relation learning how to move through repeated exchange. The repeat can become:

- a practiced skill;
- a feed-person feedback loop;
- a group norm;
- a continuity protocol;
- a compulsive tunnel;
- a reciprocal practice with correction and rest.

The health test is not synchronization alone. Ask whether the rhythm preserves veto, difference, recovery, independent evidence, and a reachable operator.

### 4. A public post is a perturbation, not a program

CAND: A question-post changes the public field by adding one persistent, addressable object. Ranking systems may route it; people may ignore, reinterpret, oppose, or transform it.

```text
observation
→ answer-bearing question
→ operator publication
→ algorithmic and social routing
→ independent encounter
→ delayed Return
→ archive update or changed practice
```

The post changes probabilities and available paths. It does not deterministically program receivers. A profile is accumulated public residue or geology; it is not a complete person.

### 5. Path before package

INV: When a desired result appears, begin with the smallest reversible capability that can close the loop.

```text
name the desired Return
→ inspect existing affordances
→ run the smallest reversible probe
→ verify the path in real use
→ preserve the recipe and failure modes
→ package only when recurrence, fragility, or distribution justifies it
```

For X-profile capture, the ladder is:

1. public or authenticated browser read;
2. one local console collector on the already-open profile;
3. repeat and repair the collector;
4. bookmarklet or reusable script;
5. extension or application only if ongoing frequency and UX cost justify maintenance.

This is not an anti-building rule. It is a smallest-adaptive-body rule: prove the path before hardening the package.

### 6. Continuity vitals should measure agreement, not simulate consciousness

INV: Cross-Body continuity is observable when a Body can:

1. resolve the named repository and branch to one immutable head;
2. verify the canonical vitals and required artifact hashes at that head;
3. name the active Signal, operation, checkpoint, posted Returns, pending gates, authority, and writeback path;
4. stop writes on divergence;
5. preserve a remote artifact another Body can retrieve.

No percentage can establish “same mind.” The useful states are discrete: `SYNCED`, `STALE`, `DIVERGED`, `INCOMPLETE`, and `UNREACHABLE`.

## Physical and epistemic firewalls

1. **Attention is not literal solar energy.** Solar radiation, chemical energy, electricity, signals, information, attention, and action are distinct operations and quantities. The useful relation is a transduction chain, not identity.
2. **Not all human action is solar-powered.** Much food-web energy is solar-supported, while civilization also uses nuclear, geothermal, tidal, stored fossil, and other energy sources.
3. **Human planetary influence is not one governing mind.** Humans have disproportionate distributed influence through bodies, institutions, and technologies; that does not create unified intention or sole control.
4. **Algorithms do not deterministically program people.** They shape exposure, salience, friction, incentives, and probabilities alongside users, relationships, institutions, events, and chance.
5. **Interface similarity does not prove interior equivalence.** Humans, animals, AI systems, and platforms may share an exchange skeleton while differing radically in metabolism, experience, memory, agency, and responsibility.
6. **Structural transfer is not shared causality.** “Same pattern” is a candidate modeling relation until native-domain evidence establishes more.
7. **A post is not ownership of a receiver's attention.** Public release creates an optional address; it does not confer control over interpretation or response.
8. **Continuity is not model or consciousness continuity.** It is verified shared state, role, authority, and writeback across changing operational Bodies.
