# Teaching Notes — Framework Theory for Curriculum Builders

> Notes ABOUT teaching the framework. NOT classroom-ready content. For curriculum developers, workshop facilitators, and mentors building their own materials from CHIMERA principles.

---

## Why This Directory Exists Separately From `teaching/`

The `teaching/` directory contains classroom-ready materials — scripted lessons, age-aware delivery, ready to drop into a session tomorrow with kids ages 3-18.

This directory (`teaching-notes/`) contains framework theory and curriculum-development reference material. The content here is for **adults building curricula** — not for kids, not for parents reading promotional material, not for first-time framework users looking for a 15-minute lesson.

The separation came from an external audit (an AI reading the framework for the first time on behalf of a real curriculum builder) flagging that the previous structure mixed classroom-ready content with framework theory. Curriculum builders need both, but they need them clearly distinguished so neither audience encounters the wrong layer.

## How to Use

**If you're building a curriculum from CHIMERA principles:** start with `teaching-guide-complete.md` — it shows how to teach at any depth. Use `chimera-rosetta-stones.md` to understand how to adapt the language for your specific community. Use `core-philosophy-simplified.md` as a quick reference once you've internalized the structure.

**If you're running adult workshops or study groups:** `triality-practical-scenarios.md` has 50+ interactive scenarios ready to use.

**If you're looking for material to deliver to kids ages 3-18:** you want `../teaching/`, not this directory.

---

## The Principle

The framework operates at multiple depths simultaneously. The classroom-ready slice (`teaching/`) keeps the philosophy implicit — kids never hear "body theory." The curriculum-builder slice (this directory) makes the philosophy explicit so adults can build their own translations.

Both are needed. They serve different audiences. Mixing them produces confusion in both directions.
