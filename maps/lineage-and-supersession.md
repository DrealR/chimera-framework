# Lineage and Supersession

CHIMERA preserves the sentence that opened a path and the sentence that later bounded it. **Superseded** means “do not use this earlier wording as the current public mechanism,” not “delete it” or “it had no value.”

|-------------------------------|----------------------------|----------------------------|

| The same physics appears at every scale | Similar shapes can have unrelated mechanisms | Reflect candidate structure across scales; classify and validate locally |

## Document status vocabulary

- **Current:** recommended public formulation.
- **Companion:** another register or audience route for the same structure.
- **Developmental:** records an earlier state of the model.
- **Carrier:** preserves a story or metaphysical picture.
- **Formal candidate:** invites domain validation; not yet established.
- **Superseded for mechanism:** retained for lineage but bounded by a later document.
- **Archive:** preserved source body, not the default entry point.

The [Complete Book](../CHIMERA-The-Complete-Book-v14.0.md) is an accumulated developmental source body. It contains current operators, older formulations, carrier stories, and formal candidates together.
