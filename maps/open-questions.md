## How to work an open question

1. Cite the seam rather than declaring it solved.
2. Gather source language and current bounded language.
3. Run Day and Night scans.
4. Seek a counterexample from another domain or body.
5. State which register each proposed answer occupies.
6. Put at least one implication through embodied practice.
7. preserve disagreement and results in Core.
8. Propose a Framework change only when the pressure changes the portable operator.

An open question is not framework weakness. It is a named membrane through which another era can enter without pretending the earlier body already knew everything.
