## Known orientation hazards

- `reemy/CHIMERA-BUILDING.md` contains strong carrier/cosmology claims mixed with engineering rules. It is now labeled source register and paired with `CHIMERA-BUILDING-GROUNDED.md`.
- Separate GitHub repositories contain relative links written as if the constellation were one directory. Prefer resolvable repository URLs or explicit local-workspace notation.
- Counts, protocol step totals, “live” status tables, and version names drift. Cite dates and observed state.
- “Universal,” “proof,” “same physics,” and “undeniable” in February snapshots are lineage markers, not automatic current authority.
- Do not use mirror synchronization to delete unique untracked work.

```text
→ graduate a bounded public formulation to Framework
→ translate through a Gut or Domain
→ apply with a real receiver/body

```

That loop lets the universe remain big without requiring every reader to ingest every era at once.
