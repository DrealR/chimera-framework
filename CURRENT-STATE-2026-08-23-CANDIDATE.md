## Candidate orientation

A useful post-Aug-8 operational description of CHIMERA is:

> **Anchor bounded bodies in what they are, explore typed relations without collapsing their differences, change representation when the current one stalls, return with what survives, preserve the path and its provenance, and compile repeated verified roads into reusable names/operators.**

This is a navigation/compilation description, not a universal theory of intelligence or reality.

## 3. Name / path / compilation distinction

Current research has sharpened a practical distinction:

> **A name is an address to a governed, unfoldable path; it is not proof that the named thing is true or that hidden reasoning is magically stored in the token.**

The useful lifecycle is:

`DISCOVER -> VERIFY -> NAME/COMPILE -> INVOKE CHEAPLY -> UNFOLD AT SEAM -> RECOMPILE IF EARNED`

Authored deterministic Name Leverage fixtures suggest compiled paths can reduce repeated online search cost in covered worlds, while wrong/stale cheap shortcuts can be harmful. Treat this as a measured fixture result, not a general LLM law.

## 4. Membrane as active boundary — candidate clarification

Recent Core work makes the boundary/body distinction more concrete:

A membrane is not merely a wall. A useful bounded interface can:

`SENSE + FILTER + EXCHANGE + SIGNAL + REPAIR + ADAPT`

The important systems lesson is not that software is literally skin. It is that **surface signal may underdetermine hidden cause**, and intervention should respect feedback delay, reversibility, and uncertainty.

Core has independently audited deterministic membrane-maintenance fixtures covering over-treatment, under-treatment, false-clear, delayed feedback, repair, and adaptation. This is currently mechanism-bearing systems evidence only; it is not a biological-equivalence or medical claim.

## 5. Conversation / handoff as observable understanding surface

Conversation does not expose another body's interior directly. It provides a repeated observable interface through which understanding can be tested and repaired.

A stronger practical test of understanding than agreement is whether a body can:

- restate a relation under a different representation;
- distinguish it from a nearby false interpretation;
- accept correction;
- transfer it to a new case;
- detect where the transfer breaks;
- return something that survives world verification.

For multi-agent systems, pure serial `A -> B -> C -> D` handoff risks telephone-style drift. Core is therefore developing **anchored handoff**: workers may transform locally while retaining a resolvable source address, declared invariants, provenance, authority, and return conditions.

This is operational continuity architecture, not a claim of shared mind or consciousness continuity.

Core applied owners include `ANCHORED-DRIFT-AND-AGENT-HANDOFF-v0.1` and the landed provenance/SurfaceGraph runtimes.

## 6. Memory / context — current candidate synthesis

The current direction increasingly separates:

```text
ACTIVE CONTEXT = current working aperture
ARCHIVE/REPOS  = persistent structure
RETRIEVAL       = task-relevant hydration
HANDOFF         = transformation + next action
TRACE           = provenance-bearing last touch
MODEL INSTANCE  = ephemeral reasoning substrate
```

The intended architecture is **ephemeral intelligence over persistent structure**.

More context is not always better; less context is not automatically better. The relevant question is whether the current body receives the minimum sufficient context plus valid addresses needed to reconstruct its task and return state.

## 7. Model evaluation — relational rather than scalar

Current benchmark work treats model performance as conditional on more than model identity:

`Fit = f(model, configuration/effort, harness, task, context/hydration, tools, evaluator, budget, observer, consequence)`

Practitioner rankings are therefore treated as observer-conditioned evidence/hypothesis sources rather than universal rankings.

Current coordinated research surfaces:

1. **CHIMERA Arena** — adaptive interaction, named techniques, regime shift, exploitability, random-null controls, cooperative DUET.
2. **Morrow Traversal** — open-ended exploration, discrimination, register fidelity, landing, null quality.
3. **Operator Fit / Model POV** — model x harness x effort x operator x task x budget x observer.
4. **Safety / provenance membrane** — sycophancy/parallax, benchmark QA, replay, failure preservation.

The first v0.1 goal is a reproducible relational evaluation program, not a universal intelligence scalar.
