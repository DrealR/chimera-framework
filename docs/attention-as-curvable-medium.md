## The claim

Attention is not a flat scoreboard. It is a **relational medium that can be curved**.

A high-visibility post creates a region of **curvature** — attention falls toward it. A comment is a **localized intervention** in that region: most introduce almost no bend (drip, then vanish); rare ones introduce real local curvature and redirect flow (secondary attractors / fusion points).

> Practice upgrade: not only *navigate* the field — **intervene skillfully** where the medium is still soft, with CHIMERA as the operating system for clean bends rather than turbulence.

Same word-physics as AI path weight, applied to the social layer: words put weight on paths; comments put weight on *shared* attention paths. See [Words Put Weight on Paths](words-put-weight-on-paths.md), [Setting the Field with Words](setting-the-field-with-words.md).

## Curvature model (structure, not cosplay)

| Attention | Spacetime / field parallel |
|-----------|----------------------------|
| High-V post | Mass warping local spacetime |
| Eyes / engagement flow | Paths following curvature |
| Typical comment | Negligible mass — no meaningful bend |
| Strong comment | Smaller mass introducing **local** curvature |
| Secondary attractor | New center of gravity inside the thread |
| Forced controversy / volume | Turbulence / distortion, not clean geodesics |
| Live density (streams) | Soft, highly responsive medium — easier to bend early |

**Key:** Effect is not only *what* you say — it is how the intervention **interacts with existing curvature** (the post’s content, timing, momentum, thread shape). Same words, different place/time → different bend.

Early in high-momentum threads the field is still **soft** (not rigid). Interventions have higher chance of real curvature before patterns harden.

## High-potential sites (where bends are more likely)

Recency + momentum remain core. Refine with **softness + opportunity**:

| Condition | Why | How to spot |
|-----------|-----|-------------|
| **Rapid growth phase** | Medium still soft; patterns not rigid | Strong V relative to age (early momentum) |
| **High-density zones** | Temporary concentration of eyes | Streams, sports, flashpoints — [Live Event Concentration](live-event-concentration.md) |
| **Distributed branch vitality** | Thread already supports secondary nodes | Multiple comments with outlier V vs trunk |
| **Emotional / narrative tension** | Built-up energy with room to redirect | Often high R, thinner C (spread with open conversation space) |
| **Resonance opportunity** | You actually have something real to say | Magnet `current_direction` / framework fit |

**Field evolution:** early-momentum flag → branch-vitality label → event keywords. Still never replace Tier 1 recency. Complementary sensor: [Search as Field Probe](search-as-field-probe.md).

## Non-interference and natural curvature

Non-interference is **not passivity**. It is deliberate: after you introduce mass, let the geodesic reveal itself.

| Do | Don’t |
|----|--------|
| Plant early while responsive | Spam-manage every reply path |
| Re-enter if *new* real contribution | Anxiety-loop the drip for views |
| Stay available to genuine replies | Force the branch into a secondary attractor |

**When re-intervention is valid:** early window still soft; genuine clarification needed; high-resonance add still true.  
**CHIMERA:** Pause before second touch; ¬F after first plant; O>I on whether continued presence still adds.

Mature posture: **Plant with integrity → step back → stay available if real engagement happens.**

## Firewall: skill vs genuine participation

As filters and curvature literacy improve, the shadow is **optimization cosplay**: “maximize bend rate” instead of authentic contribution.

The strongest bends usually come from people who are **present and have something real to say** — not from pure effect-chasing. Keep CHIMERA as **active core**, not wallpaper. Metric literacy serves genuine participation; it does not replace it. See [Genuine Live-Layer Participation](genuine-live-layer-participation.md).

## Practice reframe

| Old center | New center |
|------------|------------|
| How do I get more visibility? | Where can I create **meaningful curvature** in regions I care about? |
| Maximize V on my branch | Raise odds of clean local bend; accept most plants stay flat |
| Manage every reply path | Introduce bend → release |

### Operator loop (intervention form)

```text
1. Read medium     — recency, momentum, R/C soil, existing curvature of the post
2. Choose softness — early, high-momentum, not fully rigid spectacle
3. Craft bend      — real relation; observe/invite/slow (Holy Man); not takeover
4. Plant once      — localized intervention
5. Non-interfere   — field follows its dynamics
6. Learn           — which interventions curved vs sat flat (metric + resonance)
```
