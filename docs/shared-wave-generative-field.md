## The claim

A **Shared Wave** is a minimal generative architecture:

> Many local centers with persistent identity share one relentless tick. Each center processes from its own state (local time). Outputs become the next shared field. Emergence arises from repeated simple interaction + probability — not from scripting the story.

This is the multi-agent evolution of single-loop iterative refinement (PromptForge-style: output becomes next input). It is also the **sandbox surface** of the same physics as [Living Magnet and Resonance Pools](living-magnet-and-resonance-pools.md) on a real social graph.

## Core components

| Component | Function |
|-----------|----------|
| **Wave / shared tick** | Only strictly synchronized element; collects outputs → new shared context |
| **Local centers (agents)** | Light role + persistent memory + processing depth |
| **Relational position** | Lightweight "where I am" relative to field and others |
| **Shared rule** | Minimal orientation each tick (not a full plot) |
| **Observation layer** | Outside viewer logs emergence without constant steering |

```text
tick n:
  shared_context ← all outputs(n-1) + short memory
  for each center:
    out ← f(shared_context, local_state, relational_position, shared_rule)
  shared_context(n) ← collect(out)
```

## Local time inside a shared rhythm

- **Shared time:** the wave always comes (music that cannot stop; Interstellar wave as carrier image).
- **Local dilation:** centers with more processing depth between waves experience denser internal ticks relative to the field.
- **Relational time:** time is felt through contrast with other centers; alignment/sync is a special event, not the default.

Do not claim physics proof from the metaphor. The **operator claim** is practical: shared continuity + local state is enough to produce differentiation and occasional resonance in multi-agent loops.

## Creation vs closure (design law)

| Too closed | Too open | Healthy generative |
|------------|----------|-------------------|
| Force one answer | No shared rhythm | Shared tick + local freedom |
| Over-scripted roles | No identity | Light roles + memory |
| Max convergence | Pure noise | Allow deviation; log both |

This is the same creation-vs-closure tension as false Heaven vs living relation: frictionless forced order kills surprise; pure chaos never forms a shared present.

**Computational irreducibility (carrier):** simple rules + interaction often must be *run* to be known. That is why observation over many ticks matters more than pre-declaring the story.
