# The CHIMERA Application Circuit

> **Classification:** current AI product and workflow design instrument using electrical-circuit language as a carrier. It does not claim that attention or social relation is literally electric current.

## Design the complete circuit

An AI feature is not adequately described by its model output. Ask what complete circuit the output enters.

```text
question or tension
→ AI transformation
→ human Pause and evaluation
→ tool, relationship, or action
→ world consequence
→ evidence and memory
→ revised question
```

| Circuit carrier | Application role |
|-----------------|------------------|
| **Potential difference** | Gap between present and possible conditions; the question or need. |
| **Current** | Flow of information, attention, permission, and execution. |
| **Conductor** | Language, interface, API, institution, or relationship. |
| **Resistance** | Friction that preserves time for evaluation, learning, consent, and correction. |
| **Switch** | Pause, permission, veto, or commitment controlled by an accountable operator. |
| **Transformer** | AI changing representation, scale, complexity, or candidate space. |
| **Load** | The body or task where useful work and cost actually occur. |
| **Ground / reference** | Embodied reality and domain evidence against which output is judged. |
| **Feedback** | Consequence returning from the load. |
| **Fuse** | Stop condition when the system leaves its safe operating region. |
| **Stored charge** | Memory, unresolved tension, commitments, queues, and accumulated capacity. |

## Four failure modes

### Short circuit

Flow bypasses the identity-bearing load: automatic plans without action, decisions the user cannot evaluate, or engagement optimized without increasing operator capacity.

### Open loop

Outputs are produced, but no evidence from reality returns. Fluency accumulates without correction.

### Overload

Generation, alerts, agents, or incoming branches exceed the operator's ability to evaluate, consent, coordinate, or recover.

### Host inversion

The nominal user becomes the load or actuator for objectives selected elsewhere. The system works, but for the wrong governing center.

## The living circuit

```text
real seam
→ bounded branch generation
→ inspectable transformation
→ operator veto and selection
→ embodied work
→ measurable consequence
→ preserved learning
→ changed next question
```

The circuit is living when capability returns as increased capacity rather than only more dependence, reaction, or throughput.

## Five visible bodies

Every CHIMERA-aligned application should expose:

1. **Source:** Where did the request, signal, evidence, or claim originate?
2. **Transformation:** What did the model retrieve, infer, generate, compress, rank, or discard?
3. **Operator:** Who can redirect, contest, stop, authorize, or refuse it?
4. **Load:** What person, project, relationship, institution, or physical process should become more capable?
5. **Return:** What consequence will correct the next cycle?

Add three safety questions:

6. **Fuse:** What condition stops action before damage compounds?
7. **Residue:** What remains after completion, failure, or retirement?
8. **Recovery:** How does the body resume without hiding the path that failed?

## Firewalls

- More friction is not automatically safer; resistance must be placed where it improves judgment or protects another body.
- Human approval can be ceremonial if the person lacks time, information, skill, or real refusal.
- Feedback metrics can optimize a proxy while damaging the body the product claims to serve.
- The load must include externalized labor, environmental cost, downstream institutions, and people absent from the interface.
- A complete diagram does not prove a healthy direction; the hill and governing center still matter.

The carry line is:

> **Do not ask only what the model can output. Ask what circuit the output enters, who holds the switch, where useful work occurs, what blows the fuse, and what reality sends back.**
