## The claim

Stories keep replaying a structure: **false normal / prison → controller that benefits from sleep → spark of center → experiential seeing (gnosis) → freer participation**.

That structure maps cleanly onto **attention-field practice**. Full religious/philosophical treatment lives in [Gnostic Synthesis](gnostic-synthesis.md). Here: **operator map only**.

> Awakening is not escaping the field. It is **seeing it clearly and moving through it with integrity** — literacy + embodied orientation, not pure rebellion cosplay.

## Structure map (attention)

| Pattern element | Attention / CHIMERA read |
|-----------------|--------------------------|
| **False paradise / prison** | Automatic loops + algorithmic “normal” that feels like the only world |
| **Controller / demiurge-shape** | Any system that thrives on reactivity, distraction, surface identification (not only one villain) |
