# Teacher Path — Translate Without Flattening

CHIMERA teaching is not transferring a fixed vocabulary into every person. It is helping different bodies reconstruct a usable structure through language they can metabolize.

## Before the lesson

1. Name the learner body: age, domain, relationship, current problem, and channel.
2. Pick one operator, not the whole universe.
3. Choose a lived example the learner already knows.
4. Decide the claim's register before choosing vivid language.

## The lesson rhythm

```text
their experience → plain skeleton → familiar carrier
                 → named limit → real practice
                 → consequence → teach-back
```

Example with Pause:

- Plain: “Leave a gap between what hits you and what you do next.”
- Basketball: “Catch, read the floor, then commit.”
- Guitar: “The rest gives the next note its timing.”
- Software: “Inspect state before mutating it.”
- Firewall: none of these prove one universal causal mechanism; each trains a comparable operator in its own body.

## The Rosetta method

For every teachable concept, prepare:

- one canonical plain skeleton;
- one operator instruction;
- one story or myth carrier;
- one embodied craft example;
- one domain/formal account if warranted;
- one sentence saying what the mapping does **not** prove;
- one exercise and one counterexample;
- links to the developmental lineage.

Use the [Rosetta Card](../templates/ROSETTA-CARD.md).

## Quality checks

- Can the learner say it without CHIMERA terms?
- Can they produce a counterexample?
- Do they know which part is story and which part is mechanism?
- Did the exercise change capacity, or only produce agreement?
- Can they translate it into a second domain without losing boundary, direction, sequence, cost, or uncertainty?
- Did the lesson preserve their operator seat and right to refuse?

## Do not optimize away the human path

An AI can propose ten metaphors and generate the lesson artifact. The teacher remains responsible for the question, relationship, timing, selection, correction, and consequence. Machine for reach; body for weight.
